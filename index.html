Resume–JD Matching Tool

Compares a resume with a job description and returns an explainable 0–100 match score, with one mode for recruiters and one for job seekers.

  • Semantic matching with sentence embeddings (MiniLM), falling back to TF-IDF automatically when offline
  • Weighted scoring: must-have skills, detected from the JD’s own wording, count 3× a nice-to-have
  • Score breakdown, matched vs. missing skills, improvement suggestions and an ATS readiness check
  • Flask app with PDF/DOCX/TXT parsing and 18 unit tests
